# TechMadeEasy

A product-focused React/Vite website for TechMadeEasy.

## Run
npm install
npm run dev

## Build
npm run build

## Structure
- `/` — homepage
- `/apps` — app library
- `/apps/gambia-contacts` — Gambia Contacts product page
- `/resources` — resource library / empty state
- `/about` — brand/about
- `/connect` — YouTube + TikTok placeholders

## Before publishing
Replace the clearly marked placeholders:
- App screenshots
- Official download URL
- App version
- Download count
- Developer name
- YouTube URL
- TikTok URL

No fabricated statistics or external API data are used.
